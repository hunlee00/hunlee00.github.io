# Younghun Lee's website

Source for [hunlee00.github.io](https://hunlee00.github.io/), Younghun Lee's personal research website.

Edit `template.html` for the page layout, `_sections/` for page content, and `css/style.css` for styling. After changing any of these files, run `python3 build.py` to regenerate `index.html`. The tab icon is in `img/favicon.svg`.

The website is based on [Daniel R. Jiang's template](https://danielrjiang.github.io/).
